# 具身研习室 · Embodied Prep

面向社区共建的具身智能面试练习台。无需账号、无需 API Key、无需安装前端依赖。所有页面、题目与样式都在此目录；阅读外部论文或面经链接时才需要联网。

[社区仓库](https://github.com/ccchchch/Embodied-prepration) · [贡献内容或报告问题](https://github.com/ccchchch/Embodied-prepration/issues/new/choose) · [贡献指南](CONTRIBUTING.md)

## 备考计划版 · v0.3.0

从侧栏进入“备考计划”（`#/plan`），选择目标公司、岗位、技术方向，以及每天 3 / 5 / 10 题。目标设置独立于题库浏览筛选，不会因为临时查看其他公司而改变。

- 今日计划优先安排到期复习与薄弱题，再补未练习和已有思路的题；同类优先基础题。已经掌握且尚未到期的题目不自动填入计划。
- 完成数量按本机日期、当前目标范围内的不同题目计算，每题今天自评一次算完成。今天已自评的薄弱题仍可从“待复习”重练，但不会反复填入今日计划。
- 刷新页面、关闭页面后重新打开，均可通过“继续练习”恢复本组队列、位置和自评。临时查看其他题目时，上组进度保留。
- 可随时“结束并回顾”，区分待巩固、有思路、已掌握和未自评，并单独继续未自评或重练薄弱题。修改同组内的自评不会重复增加练习次数。
- 新开一组时，上组会进入“最近练习”；保留最近 30 组，回顾展示当时的自评快照，不受后续练习结果影响。计时器从本次打开题目开始计时，不累计离开页面的时间。
- 个人备份包含目标、未完成队列和最近回顾，兼容旧备份。合并时优先保留本机已有目标与进度；其他导入的未完成组放入最近练习，已在本机结束的组不会被旧备份重新打开。

这些数据只保存在当前浏览器，不包含在社区投稿中。进度来自个人自评，不是自动评分或面试通过率。手机端可在备考计划页导出个人备份。

## 社区共建版 · 2026-11-09

- 公司、题目、面经和学习路线都有独立链接；题库和情报的筛选条件可复制分享。
- 面经题目可逐题或整篇加入个人练习。保留出处，答案默认待整理；重复加入保留既有答案和笔记。
- 内容详情提供纠错和补充入口；社区中心支持贡献预览、本机草稿、只含投稿内容的 JSON 导出。
- 投稿入口已连接社区 GitHub 仓库，可从预览页前往 GitHub 提交。保存本机草稿不代表提交。
- 维护者通过审阅脚本记录采纳、待补充或未采纳；新社区题和公开审阅记录随版本发布。
- 薪资资料可分别查看 Offer 自述、招聘报价与转述。

参与方式见 [CONTRIBUTING.md](CONTRIBUTING.md)。代码与文档使用 MIT；外部来源材料的权利保持不变。

开发时先运行 `npm ci`，再运行 `npm test` 检查内容、逻辑与 DOM 交互；运行 `npm run build` 生成只包含公开文件的 `dist/`。仓库提供内容检查工作流。开启 GitHub Pages 的 GitHub Actions 发布方式后，可手动运行 `Publish community site` 工作流发布。

本机地址只供当前设备访问。部署到公开域名后，内容链接可分享；换域名不会自动搬迁浏览器里的个人记录，请先导出备份再导入。

## 启动

在任意终端运行：

```bash
python3 run.py
```

打开 <http://127.0.0.1:8765>。按 `Ctrl+C` 停止服务。默认仅监听本机回环地址。

端口冲突时可指定 `--port 8766`。**浏览器记录按域名和端口分别保存**，请尽量固定使用 `127.0.0.1:8765`；切换到 `localhost`、另一端口、另一浏览器或设备前，先导出备份。

## 第一版功能

- 25 家公司的备考入口：19 家国内团队、6 家海外团队；公司页可按地区、方向和关键词筛选。
- 76 道题：12 道公开面经题意整理、18 道用户截图面经、46 道研究方向专项题，覆盖 VLA、Agentic Robotics、WAM 与训练/部署基础。
- 按公司、岗位方向、来源、练习专题和技术方向组合筛选，支持关键词搜索和排序。
- 预训练专题 18 道：3 道通用大模型岗面经考点、15 道原创专项题。覆盖数据配比与清洗、监督目标、分布式训练、训练稳定性、Scaling Law、迁移评测，以及 VLA / WAM 的训练设计。
- 在题库选择“练习专题 → 预训练”，或从“学习路线 → 预训练”进入。可继续叠加公司、岗位和 VLA / WAM 筛选；个人录入题也能标记预训练专题。旧备份与学习记录继续兼容。
- 先独立作答，再展开明确结论或开放讨论；每题提供边界、学习步骤、误区、追问和资料依据。
- 收藏、作答、复盘笔记、自评与到期复习，自动保存在当前浏览器。
- 自评“还不熟悉”立即到期，“有思路”1 天后到期，“已掌握”7 天后到期。采用简单固定间隔，不是自适应记忆算法。
- 录入公司、岗位和面经；自定义题可编辑答案。未填写答案会明确标记“待整理”。
- JSON 备份导入/导出。导入采用合并策略，同一 ID 的现有题目和记录优先保留，重复导入不会重复添加。

国内入口包含：智元、宇树、星海图、自变量、银河通用、千寻智能、智平方、它石智航、灵初智能、星动纪元、星尘智能、穹彻智能、逐际动力、众擎、松延动力、原力灵机、极佳视界、无界动力，以及字节 Seed。该列表为备考覆盖，不是排名，也不代表这些公司均处于相同发展阶段。

## 原力灵机 Vol.2 截图题（2026-11-07）

本次完整收录用户提供的 18 道题，原题顺序保存在 ID 与来源编号中。选择“目标公司 → 原力灵机”“题目来源 → 公开 / 个人面经回忆”，将专题和技术方向设为“全部”，搜索 `Vol.2` 即可单独练习本组。本地版本保留原始截图入口；公开仓库和网站不分发这些截图，页面会说明来源限制。

内容覆盖遥操作与抽帧、Training-time RTC、Subtask / SFT、VLA 范式、state 与 KV Cache、RECAP 和 RLT。答案依据原论文及官方代码独立整理，含明确结论或开放分析、适用条件、学习步骤、误区和追问；截图中的推广语与个人评价未作为事实录入。截图未提供作者、原帖链接、面试日期及完整岗位名，来源说明中已标明。

RECAP 的 30% 问题明确区分正标签比例、分位数和条件 dropout，并记录 v2 正文 §V-D 与附录 A-F 的表述差异；Subtask 的收益与具体场景适配不填未经验证的数字。论文版本固定在答案引用中，官方代码核对日期为 2026-11-07。

## 内容口径

- 公司简介基于公开官网、论文或官方仓库，核对日期为 2026-11-05；技术方向不等于实时招聘岗位。
- “面经回忆”来自公开帖子或用户提供的截图，保留原文链接或本地截图，并说明是否改写。未经公司确认；回答由本项目独立整理，不照搬发帖人的回答。
- 新增预训练相关面经来自[字节通用大模型算法岗原帖（2024）](https://www.nowcoder.com/feed/main/detail/ef14567a048e4e3fa30cbe28eb5c59e3)：PPL、数据配比、预训练与 SFT 评测。原帖未公开部门，不能认定为 Seed、具身团队或专门的预训练岗位面经。列表显示“通用大模型岗 · 非具身专属”，仅在该通用岗位筛选下匹配。
- 星海图原有后训练面经仍按原岗位收录。当前没有核实到“具身预训练专岗”的独立公开面经；预训练算法工程师岗位下的题目是备考专项题，不能据此推断具体公司的面试题或招聘状态。
- “专项题”是根据研究方向整理的练习题。公司关联是备考建议，不是该公司真实问过的证据。
- WAM 指 World Action Model。遇到论文间术语差异，回答先限定具体论文和假设。
- 开放问题给分析框架和验证路径；学习步骤属于整理建议，资料链接用于核对相关原理。
- 当前没有在线 AI 对话、自动抓取面经或自动评分。自定义新题不会自动获得可靠答案，需自行填写或后续补充。

## 文件

| 文件 | 用途 |
| --- | --- |
| `data.js` | 公司、题目、公开来源、学习路线与备考匹配 |
| `dexmal-vol2.js` | 原力灵机截图的 18 道题、答案与截图登记 |
| `assets/sources/` | 本机原始截图，不提交仓库或公开站点 |

| `core.js` | 筛选、复习间隔、备份验证与合并 |

| `preparation.js` / `preparation.css` | 备考目标、今日队列、进度与练习回顾 |
| `app.js` | 界面和本地存储 |
| `styles.css` | 响应式界面 |
| `run.py` | Python 标准库本地服务器 |
| `verify.mjs` | 不依赖浏览器的逻辑与内容检查 |

如安装了 Node.js，可运行 `node verify.mjs`。本次已检查筛选交集、复习边界、学习记录序列化、备份恢复、冲突保留、不可信链接拒绝、题库完整性与 JS 语法；本地首页和 JS 模块 HTTP 响应正常。真实浏览器视觉与响应式验收仍需在使用环境完成。

内置题目随应用分发；备份保存个人题目、作答、收藏、复盘、复习记录与备考计划。服务端不收集这些记录。清理浏览器站点数据会删除本机学习记录，请定期使用备考计划页或左下角的导出按钮。
